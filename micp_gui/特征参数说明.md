## 基本参数

### 导入压汞孔隙度 (%)
- **来源**：从原始Excel文件中读取的氦气孔隙度值
- **物理意义**：代表样品的**总孔隙度**（含连通孔和闭孔）
- **测定方法**：氦气膨胀法测定，氦气分子极小可进入所有开孔

### 计算压汞孔隙度 (%)
- **公式**：`cal_porosity = max_intrusion_vol × bulk_density × 100`
- **物理意义**：基于进汞数据计算的**连通孔隙度**，反映汞能进入的孔隙占比
- **注意**：压汞孔隙度通常 ≤ 氦气孔隙度（汞无法进入闭孔和极小孔）

### 体积密度 (g/cm³)
- **公式**：`bulk_density = m / (Vp - (ma - mp - m) / 13.5939)`
- **物理意义**：样品质量除以总体积（含孔隙），即**视密度**

### 骨架密度 (g/cm³)
- **公式**：`skeletal_density = m / (denom_base - V_intrusion)`
- **物理意义**：扣除连通孔隙后的**固体骨架密度**

## 容量特征

### 孔隙体积 (mL/g)
- **公式**：`pore_volume = max(cum_intrusion)`
- **物理意义**：最大进汞累积体积，衡量材料能容纳流体的**空间总量**
- **单位说明**：mL/g 表示每克样品中所含连通孔隙的毫升数

### 总孔面积 (m²/g)
- **公式**：`Σ(4 × ΔV_i / D_pore_i)`
- **物理意义**：基于圆柱孔假设计算的累积**孔隙内表面积**
- **应用**：比表面积越大，吸附/反应能力越强

### 比表面积 (m²/g)
- **公式**：`Σ(4 × ΔV_i / D_avg_i)`，其中 D_avg 为相邻孔径的平均值
- **物理意义**：单位质量样品的**孔隙表面积**，值越大表示孔隙越发育或孔径越细小

### 平均孔径 (nm)
- **公式**：`avg_diameter = 4 × pore_volume / total_pore_area`（即4V/A）
- **物理意义**：基于4V/A假设的**平均孔径**，衡量孔隙的"平均尺度"
- **意义**：决定了流体通过的难易程度

## 几何大小

### 中值压力 Pc50 (MPa)
- **公式**：累积进汞曲线 50% 饱和度处对应的毛细管压力
- **物理意义**：**评价孔隙粗细的基准线**
  - Pc50 越小 → 孔隙越粗 → 储集性能越好
  - Pc50 越大 → 孔隙越细 → 储集性能越差

### 中值孔径 (μm)
- **公式**：`d_50 = -4σ·cosθ / Pc50`（Washburn方程）
- **物理意义**：中值压力对应的**喉道直径**，是孔隙系统粗细的综合指标

### 中值孔径(体积) (nm)
- **公式**：按累积体积从大到小排序，50%体积处对应的孔径
- **物理意义**：从**体积分布**角度衡量的中值孔径
- **关系**：与基于压力的中值孔径互补验证

### 中值孔径(面积) (nm)
- **公式**：按累积孔面积从大到小排序，50%面积处对应的孔径
- **物理意义**：从**面积分布**角度衡量的中值孔径
- **规律**：面积中值通常 < 体积中值（小孔贡献更多面积）

## 分布形态

基于 Ψ尺度变换：`Ψ = -log₂(D) - log₂(D_max)`

### 分选系数 Sp
- **公式**：`Sp = (Ψ84 - Ψ16)/4 + (Ψ95 - Ψ5)/6.6`
- **物理意义**：衡量孔隙**"整齐程度"**
  - Sp 小 → 分选好 → 孔径分布集中、结构单一
  - Sp 大 → 分选差 → 孔径分布分散、结构复杂
- **类比**：类似粒度分析中的标准偏差

### 偏度 Skp
- **公式**：`Skp = (Ψ84+Ψ16-2Ψ50)/(2(Ψ84-Ψ16)) + (Ψ95+Ψ5-2Ψ50)/(2(Ψ95-Ψ5))`
- **物理意义**：三阶矩，衡量大小孔的**偏向性**
  - Skp > 0 → **正偏（细孔为主）** → 储集性能一般
  - Skp < 0 → **负偏（粗孔为主）** → 储集性能较好
  - Skp ≈ 0 → 对称分布

### 峰态 Kp
- **公式**：`Kp = (Ψ95 - Ψ5) / (2.44(Ψ75 - Ψ25))`
- **物理意义**：四阶矩，衡量孔径分布的**集中程度**
  - Kp 高 → 分布尖锐 → 孔径高度集中 → 单一孔隙类型
  - Kp 低 → 分布平坦 → 孔径散乱分布 → 多种孔隙类型

### 半径均值 DM
- **公式**：`DM = (Ψ16 + Ψ84 + Ψ50) / 3`
- **物理意义**：Ψ尺度上的**平均孔径**，综合反映孔隙的平均粗细

### 结构系数 φ
- **公式**：`φ = DM² / Sp`
- **物理意义**：描述孔隙结构**复杂程度的综合参数**
  - 值越大 → 孔隙结构越复杂 → 流体流动阻力越大

### 相对分选系数 D
- **公式**：`D = Sp / DM`
- **物理意义**：**消除尺度效应**后的分选程度
  - 可比性更强，消除了平均孔径大小的影响

## 渗流特征

### 排驱压力 Pd (MPa)
- **公式**：对低饱和度段(S<40%) 做 logP ~ Sat 线性回归，截距 = Pd
- **物理意义**：非润湿相（汞）开始进入样品的"**第一道门槛**"
  - Pd 越小 → 最大喉道越大 → 流体越容易进入 → 渗透性越好
  - Pd 越大 → 最大喉道越小 → 流体越难进入 → 渗透性越差
- **别名**：门槛压力、突破压力

### 最大孔径 (μm)
- **公式**：`d_max = -4σ·cosθ / Pd`
- **物理意义**：排驱压力对应的**最大连通喉道直径**
- **意义**：决定了流体进入样品的难易程度上限

### 进汞饱和度 (%)
- **公式**：`intrusion_saturation = cal_porosity / he_porosity × 100`
- **物理意义**：**连通孔隙占比**
  - 100% → 压汞孔隙度 = 氦气孔隙度 → 无闭孔
  - < 100% → 存在闭孔或不连通孔

### 退汞效率 We (%)
- **公式**：`We = (1 - V_residual/V_max) × intrusion_saturation`
- **物理意义**：描述流体被**困住的程度**
  - We 高 → 死孔和颈口孔少 → 孔隙连通性好
  - We 低 → 死孔和颈口孔多 → 孔隙连通性差
- **水动力学意义**：退汞效率越高，油气采收率越高

### 突破压力比
- **公式**：`ratio = P_avg / Pd`
- **物理意义**：平均进汞压力与排驱压力之比，反映克服门槛后的**整体进汞阻力**

## 连通特征

### 特征长度 (nm)
- **公式**：`characteristic_length = d_max`
- **物理意义**：最大连通喉道直径，描述孔隙网络的特征尺度

### 导电地层因子
- **公式**：`F = (d_median / d_max)²`
- **物理意义**：基于孔喉比的**有效导电截面估计**
  - F 越小 → 导电性越好 → 孔隙连通性越好

### 迂曲度因子
- **公式**：`τ_factor = 1 / √F`
- **物理意义**：描述孔隙通道的**弯曲程度**
  - 弯曲度越大 → 流体实际流经路径越长 → 传输效率越低

### 迂曲度
- **公式**：`Tortuosity = τ_factor / porosity`
- **物理意义**：考虑**孔隙率修正**的迂曲度
  - 综合反映孔道弯曲程度与孔隙率的影响

## 空间复杂性

### 分形维数 D
- **公式**：`D = 3 + slope(log(1-S) ~ logP)`
- **物理意义**：描述孔隙空间的**填充能力和粗糙度**
  - 2 < D < 3
  - D 越大 → 表面越粗糙 → 空间填充越复杂
  - D ≈ 2 → 表面光滑 → 理想填充
  - D ≈ 3 → 极度粗糙 → 空间填充型分形

### 逾渗分形维数
- **公式**：`D_p = 3 + slope(log(1-S) ~ logP)`，限定低压力区域 (logP ≤ 2)
- **物理意义**：逾渗阈值附近的**孔隙网络特征**
  - D_p 越接近 3 → 逾渗网络越发达
  - 反映孔隙网络的连通性和逾渗通道特性

## 渗透率

### 基质渗透率 (m²)
- **公式**：`k_matrix = (1/89) · (Lmax)² · (Lmax/Lc) · φ · (Vc/Vtot)`（Swanson方法）
- **孔径区间**：10-100 μm
- **物理意义**：反映**基质孔隙**的流体传输能力
- **Swanson参数**：Lc = (S·D³)最大值对应的孔径；Vc = 对应饱和度

### 裂缝渗透率 (m²)
- **公式**：同上，使用 1-10 μm 孔径范围
- **物理意义**：反映**裂缝/大孔**的流体传输能力
- **注意**：若孔径 < 1 μm 则裂缝渗透率为 0

## 参数分类总结

| 类别 | 参数 | 核心问题 |
|------|------|----------|
| 容量特征 | 总压汞量/孔隙度 | 能容纳多少流体？ |
| 大小特征 | 平均孔径/中值孔径 | 孔隙平均尺度？ |
| 分布特征 | 分选系数 | 孔隙整齐程度？ |
| 形态特征 | 歪度 | 偏大孔还是偏小孔？ |
| 形态特征 | 峰度 | 孔径集中还是散乱？ |
| 渗流特征 | 排驱压力 | 进入的最难关卡？ |
| 连通特征 | 退汞效率 | 孔隙通畅程度？ |
| 空间特征 | 分形维数 | 表面粗糙/复杂程度？ |

## Ψ尺度变换说明

Ψ尺度是将孔径（nm）转化为对数尺度的方法，是计算分选系数、歪度、峰态等参数的基础：

```
Ψ = -log₂(D) - log₂(D_max)
```

其中 D 为孔径(nm)，D_max 为最大孔径(nm)。

在 Ψ 尺度上，累积体积百分比对应的 Ψ 值通过插值得到（16%, 25%, 50%, 75%, 84%, 5%, 95%），然后计算各统计参数。这种方法源自沉积学中的粒度分析方法（Folk & Ward, 1957）。
